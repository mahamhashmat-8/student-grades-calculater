# 🎓 Student Grade Calculator

A beginner-friendly Python project that calculates a student's total marks, percentage, and grade based on marks entered for three subjects.

## 📌 Features

- Takes the student's name as input
- Takes marks for Python, English, and Mathematics
- Calculates total marks
- Calculates percentage
- Assigns a grade based on the percentage
- Displays the final result clearly

## 🛠️ Technologies Used

- Python 3

## 📚 Python Concepts Practiced

- Variables
- User input
- `float()`
- Arithmetic operations
- `if`, `elif`, and `else`
- Formatted strings (`f-strings`)

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Clone this repository:
3.Open the project folder:
cd student-grade-calculator
4.Run the program:
python student_grades_calculator.py
